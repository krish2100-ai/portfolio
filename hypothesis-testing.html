Hypothesis Testing

A framework for deciding whether a result is likely real or just noise.

Hypothesis testing is a foundational method in statistics for checking claims about data. It lets us decide whether an observed pattern is strong enough to support a conclusion, or whether it may be explained by random variability alone.

The process typically begins by stating two competing hypotheses: a null hypothesis, which usually represents no effect or no difference, and an alternative hypothesis, which represents the effect being investigated. We then ask whether the observed data would be unusually unlikely under the null hypothesis.

How the test works

A statistical test summarizes the evidence in a single number, often a test statistic, and compares it against a reference distribution. This produces a p-value: the probability of observing data at least as extreme as the sample if the null hypothesis were true. Lower p-values suggest the data are less compatible with the null hypothesis.

A useful way to think about the decision rule p-value < 0.05 is as a classifier. The classifier looks at the observed statistic and labels the result as either “statistically significant” or “not significant.” Just like any classifier, it can be right or wrong, and its behavior is best understood through the same precision/recall vocabulary.

Decision \ Truth Real effect (H₁ true) No effect (H₀ true)
Mark significant True positive (correct) False positive (Type I error)
Mark not significant False negative (Type II error) True negative (correct)
  • Power = recall on the “real effect” class. It is the chance of marking the result significant given that a real effect exists: P(significant | H₁ true). Higher power means the test reliably catches true effects.
  • The significance level α is the false-positive rate. It is the chance of marking the result significant given that there is no real effect: P(significant | H₀ true). Equivalently, if we call recall on the “no effect” class the specificity, then α = 1 − specificity. Setting the threshold at 0.05 caps this false-positive rate at 5%.

So choosing a threshold like 0.05 is really choosing an operating point on this classifier: a lower threshold reduces false positives (fewer flukes called significant) but also lowers power (more real effects missed). This is the same precision–recall trade-off that appears throughout machine learning.

A worked example: difference of means

Suppose we compare the means of two populations with different variances — for example the average spend of users in two product variants. The test statistic is the difference in sample means, and under the null hypothesis this difference is centered at zero. Under the alternative, it is centered at the true effect size. The two figures show distribution of difference between sample means from two groups under H₀ (no effect) and H₁ (real effect).

Figure 1 — Original sample size. The two distributions overlap heavily, so the test has limited power.

Figure 2 — Sample size increased 4×. The standard error halves (SE ∝ 1/√n), so both distributions are squeezed and separate cleanly, raising power.

Stacking the two figures makes the key insight visible: the true effect size μ has not changed, but with 4× the data the sampling distributions become much narrower. The overlap between H₀ and H₁ shrinks, which directly increases the power (recall) of the test — the same real effect that was hard to detect in Figure 1 is now easily separated from noise in Figure 2.

A confidence interval is the flip side of the same picture. Instead of asking “is the difference far enough from 0?”, it draws a band around the observed difference — typically the estimate ± about two standard errors — that captures the plausible range for the true effect. Its width is set by the same standard error that controls the spread of these curves. In Figure 1 the wide, overlapping distributions correspond to a wide confidence interval that still includes 0, so the result is inconclusive. In Figure 2 the squeezed distributions correspond to a narrow confidence interval that no longer includes 0. A useful rule of thumb: the result is statistically significant at the 5% level exactly when the 95% confidence interval does not contain 0.

Why draw a band at all? The observed difference is only an estimate from one random sample — draw a different sample and you would get a slightly different number. That sampling variability is exactly the bell curve in the figures, and its spread is the standard error. So a single point estimate is almost never exactly right; the honest thing to report is a range of values that are consistent with the data. We build that range by inverting the test: a candidate value for the true difference is “plausible” if the observed estimate would not be surprising when that value is true — i.e. it falls within about two standard errors. Collecting every such plausible value gives the band. The ± 2×SE width therefore comes directly from the sampling distribution: because roughly 95% of sample estimates land within two standard errors of the truth, an interval of ± 2×SE around the estimate will, over repeated sampling, cover the true difference about 95% of the time.

Numerical example: Welch’s t-test

When the two populations have different variances, the appropriate test is Welch’s t-test (it does not assume equal variances). Suppose we measure average spend in two variants:

GroupSample size nMean x̄Std dev s
Variant A30528  (s² = 64)
Variant B404812 (s² = 144)

Step 1 — Standard error of the difference:

SE = √(s₁²/n₁ + s₂²/n₂) = √(64/30 + 144/40) = √(2.133 + 3.600) = √5.733 = 2.394

Step 2 — t statistic:

t = (x̄₁ − x̄₂) / SE = (52 − 48) / 2.394 = 4 / 2.394 = 1.671

Step 3 — Welch–Satterthwaite degrees of freedom:

df = (s₁²/n₁ + s₂²/n₂)² / [ (s₁²/n₁)²/(n₁−1) + (s₂²/n₂)²/(n₂−1) ] = 5.733² / (2.133²/29 + 3.600²/39) = 32.87 / (0.157 + 0.332) ≈ 67

Step 4 — Decision:

The two-tailed critical value at α = 0.05 with df ≈ 67 is about ±1.996. Since our t = 1.671 is smaller in magnitude, we fail to reject the null. The two-tailed p-value is roughly 0.10 — the observed difference of 4 is not statistically significant at the 5% level, even though it may look meaningful.

Step 5 — 95% confidence interval for the difference:

CI = (x̄₁ − x̄₂) ± tcrit × SE = 4 ± 1.996 × 2.394 = 4 ± 4.78 = (−0.78, 8.78).

Interpretation: if we repeated this experiment many times, about 95% of the intervals computed this way would contain the true mean difference. Because this interval includes 0, a “no difference” value is still plausible — which is exactly why the test fails to reject the null. The interval also shows the difference could realistically be anywhere from slightly negative to nearly 9, so the estimate is too imprecise to act on.

Now increase both sample sizes 4× (n₁ = 120, n₂ = 160), keeping the same means and standard deviations:

SE = √(64/120 + 144/160) = √(0.533 + 0.900) = √1.433 = 1.197
t = 4 / 1.197 = 3.34, with df ≈ 275 and critical value ≈ ±1.969.

The new 95% confidence interval is 4 ± 1.969 × 1.197 = 4 ± 2.36 = (1.64, 6.36). Interpretation: this interval excludes 0, so a “no difference” value is no longer plausible — consistent with the significant result. Note it is also much narrower than the original (−0.78, 8.78): with 4× the data the estimate is far more precise, which is the confidence-interval counterpart of the squeezed distributions in Figure 2.

Now t = 3.34 far exceeds 1.97, giving a two-tailed p-value of about 0.001 — the same effect is now highly significant. This is exactly the squeezing shown in Figure 2: quadrupling the sample halves the standard error (SE ∝ 1/√n), shrinks the overlap, and turns an undetectable difference into a clear one.

What about the Type I error? It does not change. The Type I error rate is fixed by the chosen threshold (α = 0.05), so it stays at 5% regardless of sample size — we simply use a larger critical value of df but the same 5% tail area. Increasing the sample size does not make false positives more or less likely; it only reduces the Type II error (raising power). In Figure 2, both curves narrow, but the H₀ curve still has exactly 5% of its area beyond the critical value. So the benefit of more data is entirely on the recall side: better detection of real effects at the same false-positive rate.

Why it matters

Hypothesis testing helps separate signal from noise in decision-making. In scientific work, it allows researchers to assess whether a new treatment effect, model improvement, or observed pattern is likely to be genuine rather than an artifact of randomness. In business and product settings, it helps avoid acting on unstable or short-lived signals.

Important limitations

Hypothesis testing is not a guarantee of truth and it does not measure the size of an effect on its own. A result can be statistically significant but small, while an important effect can be missed if the sample is too small or the design is weak. That is why statistical testing is often paired with confidence intervals, effect sizes, and domain context.

In practice, the best decisions come from combining formal tests with careful measurement, replication, and interpretation. Good inference depends not only on whether a result is surprising, but on whether it is meaningful in the real world.
